## 2. Sécurité Implémentée

### 2.1 Firewall (UFW)
```bash
# Politique par défaut : DENY (entrant ET sortant)
sudo ufw default deny incoming
sudo ufw default deny outgoing

# Ports autorisés
sudo ufw allow 22/tcp   # SSH
sudo ufw allow 80/tcp   # HTTP
sudo ufw allow 443/tcp  # HTTPS
sudo ufw allow out 53   # DNS
sudo ufw allow out 80   # HTTP sortant
sudo ufw allow out 443  # HTTPS sortant
sudo ufw allow out 123/udp  # NTP
```

### 2.2 Fail2ban
- **Jail SSH** : 3 tentatives max, ban 24h
- Action : blocage via UFW
- Fichier de config : `/etc/fail2ban/jail.local`

### 2.3 SSH Hardening
Fichier : `/etc/ssh/sshd_config.d/99-hardening.conf`
```
PasswordAuthentication no
PermitRootLogin no
MaxAuthTries 3
LoginGraceTime 30
AllowUsers deploy
```

## 5. Commandes Utiles

### Gestion des conteneurs
```bash
cd /var/www/smartplanning

# Voir les logs
docker compose logs -f app

# Redémarrer l'application
docker compose restart app

# Mettre à jour l'image
docker compose pull app && docker compose up -d app

# Voir le statut
docker compose ps
```

### Sécurité
```bash
# Voir les IPs bannies
sudo fail2ban-client status sshd

# Débannir une IP
sudo fail2ban-client set sshd unbanip <IP>

# Statut firewall
sudo ufw status verbose
```

### SSL Let's Encrypt
```bash
# Obtenir un certificat (après config DNS)
sudo certbot certonly --webroot -w /var/www/smartplanning/certbot \
  -d smartplanning.fr -d www.smartplanning.fr \
  --non-interactive --agree-tos --email contact@smartplanning.fr

# Copier vers le dossier nginx
sudo cp /etc/letsencrypt/live/smartplanning.fr/* /var/www/smartplanning/ssl/live/smartplanning.fr/
sudo chown -R deploy:deploy /var/www/smartplanning/ssl/

# Redémarrer nginx
docker compose restart nginx
```
