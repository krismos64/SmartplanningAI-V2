## 🔒 Contexte Sécurité

### Raison du remplacement
L'ancien VPS (141.94.78.0) a subi **3 attaques en 12 jours** :

1. **5 décembre 2025** : UDP Flooder (attaque DDoS)
2. **15 décembre 2025** : Cryptominer injecté (via CVE Next.js CVSS 10.0/10)
3. **16 décembre 2025** : DNS Amplification → VPS bloqué par OVH

**Décision** : Résilier l'ancien VPS et migrer vers un nouveau serveur avec hardening complet.

## 📚 Scripts et Documentation Associés

### Script de hardening principal
- **Fichier** : `scripts/secure-vps-part1.sh`
- **Description** : Script bash automatisé de sécurisation Ubuntu 24.04
- **Fonctionnalités** :
  - Mise à jour système
  - Création utilisateur `deploy` (pour GitHub Actions)
  - Durcissement SSH (désactivation root, clés uniquement)
  - Installation Docker + sécurisation daemon
  - Configuration UFW (firewall strict OUTGOING)
  - Blocage des 5 IPs malveillantes identifiées
  - Installation fail2ban (protection brute-force)
  - Instructions manuelles finales

### Configuration Docker
- **Fichier** : `docker/docker-compose.prod.yml`
- **Hardening OWASP** :
  - `read_only: true` (filesystem lecture seule)
  - `tmpfs` mounts (répertoires temporaires en RAM)
  - `security_opt: no-new-privileges` (pas d'escalade de privilèges)
  - `cap_drop: ALL` + `cap_add` minimal (principe du moindre privilège)
  - Resource limits (protection DoS)
  - Healthchecks actifs

### Configuration Nginx
- **Fichier** : `nginx/smartplanning.conf`
- **Sécurité** :
  - Rate limiting par zone (auth: 3 req/min, API: 30 req/s, général: 10 req/s)
  - Blocage extensions dangereuses (.php, .env, .asp, etc.)
  - Headers de sécurité (X-Frame-Options, CSP complémentaire, etc.)
  - Gzip compression
  - Support WebSocket (HMR Next.js)
  - Certificat SSL Let's Encrypt

### Pipeline CI/CD
- **Fichier** : `.github/workflows/cd.yml`
- **Processus** :
  1. Build image Docker (Next.js + Prisma)
  2. Push vers GitHub Container Registry (ghcr.io)
  3. Connexion SSH au VPS
  4. Pull image et redémarrage conteneurs
  5. Migrations Prisma automatiques
